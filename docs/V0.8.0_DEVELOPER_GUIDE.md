# v0.8.0 Developer Quick Start

## 🚀 Getting Started with v0.8.0 Development

### Prerequisites

- Go 1.24+
- Git
- CGO enabled
- Platform-specific build tools (gcc/clang)

### Setup Development Environment

```bash
# Clone and switch to v0.8.0 branch
git clone https://github.com/greysquirr3l/gorm-duckdb-driver.git
cd gorm-duckdb-driver
git checkout feature/v0.8.0-duckdb-module-migration

# Install dependencies (current deprecated module)
go mod download

# Run tests to establish baseline
go test -v ./...
```

---

## 📝 Key Migration Tasks

### 1. Update Module Dependency

```bash
# Remove old module
go mod edit -droprequire github.com/marcboeker/go-duckdb/v2

# Add new module
go get github.com/duckdb/duckdb-go@latest

# Tidy dependencies
go mod tidy
```

### 2. Update Imports

**Find all occurrences:**
```bash
grep -r "marcboeker/go-duckdb" . --exclude-dir=vendor --exclude-dir=.git
```

**Replace pattern:**
```go
// OLD
import duckdb "github.com/marcboeker/go-duckdb/v2"

// NEW
import "github.com/duckdb/duckdb-go"
```

### 3. Test Changes

```bash
# Run specific test suite
go test -v -run TestConnection
go test -v -run TestDialector
go test -v -run TestGORMInterfaceCompliance

# Run all tests
go test -v ./...

# Run with race detection
go test -race ./...

# Run benchmarks
go test -bench=. ./...
```

## 🐛 Common Issues & Solutions

### Issue: CGO Build Failures

```bash
# Ensure CGO is enabled
export CGO_ENABLED=1

# Install build tools
# macOS
xcode-select --install

# Ubuntu/Debian
sudo apt-get install build-essential

# Windows
# Install MinGW-w64
```

### Issue: Module Resolution Errors

```bash
# Clear module cache
go clean -modcache

# Re-download dependencies
go mod download

# Verify go.sum
go mod verify
```

### Issue: Test Failures

```bash
# Run with verbose output
go test -v -run FailingTest

# Run with race detection
go test -race -run FailingTest

# Check for platform-specific issues
GOOS=linux GOARCH=amd64 go test ./...
```

## 🔄 Git Workflow

### Branch Strategy

```bash
# Work on feature branch
git checkout feature/v0.8.0-duckdb-module-migration

# Create sub-branches for specific tasks
git checkout -b feature/v0.8.0-module-update
git checkout -b feature/v0.8.0-testing
git checkout -b feature/v0.8.0-docs
```

### Commit Messages

```
feat(core): migrate to official duckdb-go module
fix(migrator): update DDL generation for new API
test(integration): add platform-specific tests
docs(migration): create v0.8.0 migration guide
```

### Pull Request Process

1. Create PR against `feature/v0.8.0-duckdb-module-migration`
2. Ensure all tests pass
3. Update documentation
4. Request review
5. Address feedback
6. Merge when approved
